🧾 One-Click Resume Builder

A sleek one-page resume builder built with React + Vite + Tailwind CSS.  
Create, preview, switch templates, and download your resume as a **PDF in one click**.
  
📂 Repo: https://github.com/Pragati-03/resume-builder

---

 ✨ Highlights

- ⚡ Fast & lightweight (Vite + React)
- 🎨 Clean UI with Tailwind CSS
- 📄 Multiple resume templates (Classic, Modern)
- 🔁 Real-time preview
- ➕ Multiple education entries
- 🌐 Optional links (GitHub, Portfolio, City)
- 🏆 Extra sections: Hackathons, Hobbies, Languages
- 📥 One-click PDF export

---

🛠 Tech Stack

React · Vite · Tailwind CSS · jsPDF · html2canvas · GitHub Pages

---

🚀 Run Locally

```bash
git clone https://github.com/Pragati-03/resume-builder.git
cd resume-builder
npm install
npm run dev
